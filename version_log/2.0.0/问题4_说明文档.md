# 问题 4 说明文档 — A/B 混合体系最低成本组合

> 版本：2.0.0 ｜ 日期：2026-08-08 ｜ 说明文档（不构成论文）｜ 主流程 Monte Carlo 已运行（seed=42，二分 trials=500，confirm=4000），结果见 §6

---

## 1. 问题重述

几何设置同问题 2/3：微构体为边长 10000nm 的立方体 `Ω=[-5000,5000]³`（体积 `V₀=10¹² nm³`），介质 A 为直圆柱（长 `L_A=5000nm`、半径 `R_A=30nm`，单根体积 `V_A=π·30²·5000≈1.4137×10⁷ nm³`），左右带电面 `x=±5000`，导通判据最短距离 `≤ δ=1.8nm`。

**新增介质 B**：半径为 `R_B=200nm` 的球形颗粒，球心在 `[-4800,4800]³` 内均匀分布（球完全在盒内，球心不越过电极面 ±4800）。

成本：
- 介质 A：`1.05 元/μm³`（`V_A=0.01414 μm³`，单根 ≈0.0148 元）
- 介质 B：`0.05 元/μm³`（`V_B=4/3π·200³≈3.351×10⁷ nm³=0.03351 μm³`，单球 ≈0.0017 元）

**问题 4：求满足导通概率 `P_conn ≥ 0.90` 的最低成本组合 `(N_A*, N_B*)`**，即

```
min  C(N_A, N_B) = 1.05·N_A·V_A/10⁹ + 0.05·N_B·V_B/10⁹   （元）
s.t. P_conn(N_A, N_B) ≥ 0.90（95% Wilson 单侧置信下界判定）
     N_A ∈ [0, 360]，N_B ∈ [0, 5000]（搜索范围）
```

## 2. 建模与方法

### 2.1 三种导通判据（A-A、A-B、B-B、B-电极）

| 判据 | 阈值（nm） | 说明 |
|---|---|---|
| A-A 圆柱间最短距离 | `2R_A+δ = 61.8` | 胶囊近似，同 Q1-Q3 |
| A-B 点-线段距离 | `R_A+R_B+δ = 231.8` | 球心到 A 轴线段的最短距离 |
| B-B 球心距离 | `2R_B+δ = 401.8` | 两球表面接触（球心距 ≤ 半径和） |
| B-电极平面 | `R_B+δ = 201.8` | 球心到电极平面 `x=±5000` 的距离（球面到平面 ≤ δ） |

B 球每颗为独立节点（不做周期合并）；A 圆柱沿用 Q1-Q3 的 PERIODIC 切段/合并语义。

### 2.2 概率云理论：双介质连接矩阵

将 Q2 的概率云理论推广到双介质：令 `ρ_A = N_A/V₀`、`ρ_B = N_B/V₀`，连接矩阵为对称 2×2：

```
M = [[ ρ_A·V_AA,   ρ_B·V_AB ],
     [ ρ_A·V_AB,   ρ_B·V_BB ]]
```

其中：
- `V_AA = 2.5493×10⁹ nm³`（Q2 已求，A-A 二体连接体积）
- `V_BB = 4/3π·(2R_B+δ)³ = 4/3π·401.8³ ≈ 2.7172×10⁸ nm³`（B-B 解析，接触球体积）
- `V_AB = 4π∫r²·q_AB(r)dr`（A-B 二体连接体积，MC 采样 q_AB 后数值积分，dr=25nm；实测 `9.0877×10⁸ nm³`，与胶囊近似 `πR_AB²L_A+4/3πR_AB³ ≈ 8.9618×10⁸ nm³` 相对偏差 1.4%）

**理论筛选指标**：`λ_max(M) ≥ 1` 作为理论可行区的判据（均值场渗流直觉：连接矩阵主特征值 ≥1 对应体系整体出现贯通倾向）。Level 1 在 `N_A×N_B` 网格（步长 10×100）上扫描 λ_max，得到理论可行区。

### 2.3 三级搜索流程

1. **Level 1 理论筛选**（快）：`N_A×N_B` 网格扫描 `λ_max(M)`，`λ_max≥1` 的点构成理论可行区，缩小 MC 搜索范围。
2. **Level 2 MC 边界**：对每个 `N_A` 网格点（步长 10），在 `N_B∈[0,5000]` 上**整数二分最小 N_B** 使判定达标（`wilson_one_sided_lower(95%) ≥ 0.90`，每评估点 `trials=500`），得到可行边界 `N_B_min(N_A)`，并做单调性校验（N_A 增大 → N_B_min 不应增大）。
3. **Level 3 成本优化与确认**：沿边界计算 `total_cost`，取成本最小候选点；对候选及其 8 邻域（`N_A±10`、`N_B±50`）用 **`confirm_trials=4000`** 复核，取达标点中成本最小者为最优 `(N_A*, N_B*)`。

附加 **Level 2.5 MC 粗网格热图**（N_A 步长 60 × N_B 步长 1000，每点 `trials=300`）供 Figure 7 可视化。

### 2.4 判定标准：95% Wilson 单侧置信下界（同 Q3）

判定采用 **`p_lower,95% ≥ 0.90`**（Wilson 单侧下界，z=1.645），非点估计 `p̂≥0.90`。二分用 `trials=500`（每点判定波动 ≈±1.3%），最终结论用 `confirm_trials=4000` 复核（波动 ≈±0.5%）。

### 2.5 可复现性

沿用 Q3 机制：主 rng（seed=42）一次性派生 `bisect/confirm/mc_grid` 三个子种子池；评估顺序固定（逐模式、逐 N_A、逐二分迭代）；`--workers 8` 并行，结果与串行一致。A-B 的 q_AB(r) 采样与 V_AB 积分固定种子（seed+1000 / +2000）。

## 4. 概率云理论结果（Level 1）

- `V_AA = 2.5493×10⁹ nm³`、`V_BB = 2.7172×10⁸ nm³`、`V_AB = 9.0877×10⁸ nm³`（胶囊近似 8.9618×10⁸，相对偏差 1.4%）
- **理论可行区（λ_max≥1）**：`N_A∈[0,360], N_B∈[400,5000]`（Level 1 网格）

即纯 B 体系理论需要 N_B≥400 才可能贯通，而 A 的加入可显著降低所需 B 数量。

## 5. Level 2 MC 边界结果（可行边界 N_B_min(N_A)）

| N_A | periodic N_B_min | wrapped N_B_min |
|---|---|---|
| 0~300 | 不可行（>5000） | 不可行（N_A=280 例外：5000 达标） |
| 310 | 4370 | 3123 |
| 320 | 3099 | 3746* |
| 330 | 2414 | 2499 |
| 340 | 2581* | **0** |
| 350 | 2540 | 1960* |
| 360 | **0** | 0 |

（* 处违反单调性假设，500 trials 统计波动所致；Level 3 已用 4000 次复核修正结论）

关键观察：
- **N_A ≤ 300 时，即使 N_B=5000 也基本无法达标**——纯 B/低 A 体系成本高达 9~12 元；
- **N_A ≥ 340 时，纯 A 已接近达标**（N_B_min 骤降至 0 附近）；
- 边界在 N_A≈340~360 处急剧下降，与 λ_max 理论可行区（N_A∈[0,360] 均理论可行）相比，**实际 MC 边界明显更苛刻**：理论 λ_max≥1 是均值场判据（对应 k̄≈1），而 P_conn≥0.90 需要更强的连接，与 Q3 观察一致。

## 6. 最终结果（Level 3，confirm_trials=4000）

### 6.1 双模式最优解

| boundary_mode | N_A* | N_B* | 最低成本（元） | p̂ | p_lower,95% | 结论 |
|---|---|---|---|---|---|---|
| periodic_connected | 360 | 0 | **5.3438** | 0.9147 | 0.9072 | 纯 A 体系达标 |
| wrapped_geometry_only | 340 | 50 | **5.1307** | 0.9095 | 0.9018 | A 为主 + 少量 B 桥接 |

### 6.2 确认点明细（periodic_connected）

| N_A | N_B | cost | p̂ | p_lower,95% | 达标 |
|---|---|---|---|---|---|
| 350 | 0 | 5.1954 | 0.9075 | 0.8997 | 否（临界） |
| 350 | 50 | 5.2792 | 0.9052 | 0.8974 | 否 |
| **360** | **0** | **5.3438** | 0.9147 | **0.9072** | **是 → 最优** |
| 360 | 50 | 5.4276 | 0.9103 | 0.9025 | 是 |

### 6.3 确认点明细（wrapped_geometry_only）

| N_A | N_B | cost | p̂ | p_lower,95% | 达标 |
|---|---|---|---|---|---|
| 330 | 0 | 4.8985 | 0.9030 | 0.8950 | 否（临界） |
| 330 | 50 | 4.9823 | 0.8992 | 0.8911 | 否 |
| 340 | 0 | 5.0470 | 0.9052 | 0.8974 | 否（临界） |
| **340** | **50** | **5.1307** | 0.9095 | **0.9018** | **是 → 最优** |
| 350 | 0 | 5.1954 | 0.8992 | 0.8911 | 否 |
| 350 | 50 | 5.2792 | 0.9130 | 0.9054 | 是 |

### 6.4 结论与解读

1. **最低成本组合以介质 A 为主（N_A*=340~360），B 球仅作少量补充**（wrapped 模式加 50 颗）。B 球虽单价便宜（0.05 vs 1.05 元/μm³，单球成本约为单根 A 的 1/9），但体积大（0.0335 vs 0.0141 μm³）、点接触导电效率低，**纯 B 体系需数千颗才能达标（成本 12+ 元），远不如以 A 为主**。
2. 成本结构：`periodic (360,0) = 5.34 元`、`wrapped (340,50) = 5.13 元`。加 50 颗 B（0.08 元）换来 N_A 从 350 降至 340（省 10 根 A ≈ 0.15 元）——**B 球在 N_A 临界区有桥接替代价值**。
3. **统计临界说明**：periodic 的 (350,0) 与 wrapped 的 (340,0) 在 4000 次复核下 `p_lower` 分别为 0.8997 / 0.8974，**略低于 0.90**（二分 500 次判定时曾达标，属抽样波动）；最终结论以 4000 次复核为准，如实记录临界点。
4. **理论-仿真对照**：λ_max 理论可行区给出 N_A∈[0,360] 均理论可行，但 MC 表明实际可行需要 N_A≳310（且 N_A<310 时 N_B=5000 也不够）。理论与仿真方向一致（A 越多所需 B 越少），但实际边界比理论均值场临界更苛刻——与 Q3 的 φ_min 略低于理论值同源（链式连接的渗流行为偏离均值场）。
5. **运行时长**：完整三级流程（seed=42，workers=8，双模式）总耗时 **8126s（135.4 分钟）**。
