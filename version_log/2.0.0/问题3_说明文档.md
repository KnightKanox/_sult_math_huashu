# 问题 3 说明文档 — P_conn≥90% 的最低介质 A 体积分数

> 版本：2.0.0 ｜ 日期：2026-08-07 ｜ 说明文档（不构成论文）｜ 主流程 Monte Carlo 待运行，结果表为占位

## 1. 问题重述

几何设置同问题 2：微构体为边长 10000nm 的立方体 `Ω=[-5000,5000]³`（体积 `V₀=10¹² nm³`），介质 A 为直圆柱（长 `L_A=5000nm`、半径 `R_A=30nm`，单根体积 `V_A=π·30²·5000≈1.4137×10⁷ nm³`），左右带电面 `x=±5000`，导通判据最短距离 `≤ δ=1.8nm`。

问题 3：**求满足导通概率 `P_conn ≥ 0.90` 的最低介质 A 体积分数 `φ_min`**（介质 A 随机填充）。

## 2. 建模与方法

### 2.1 二分搜索原理

`P_conn` 随体积分数 `φ` **单调不减**（填充的介质 A 越多，连通可能性越大），满足二分搜索的单调性前提：

1. 设搜索区间 `[φ_low, φ_high] = [0.20%, 0.70%]`：
   - 下界 0.20% 处于渗流临界区以下（`k̄≈0.36`，远低于 1），预期 `P_conn` 不满足；
   - 上界 0.70% 由问题 2 实测满足（`P̂=0.975`，95% 单侧下界远高于 0.90）。
2. 每轮取中点 `φ_mid = (φ_low + φ_high)/2`，在该填充率下跑 `trials=1000` 次 MC：
   - 若判定"满足"→ 收缩上界 `φ_high = φ_mid`（尝试更低）；
   - 否则 → 抬高下界 `φ_low = φ_mid`。
3. 终止条件：`φ_high - φ_low ≤ tol`（`tol=0.0001`，即 0.01%）或迭代达最大次数 40（理论上 `log₂(0.005/0.0001)≈5.6` 轮即收敛，40 为安全上限）。
4. 收敛后取 `φ_min = φ_high`（最后确认满足的最小上界）。

### 2.2 判定标准：95% Wilson 单侧置信下界

判定采用 **95% Wilson 单侧置信下界 `p_lower,95% ≥ 0.90`**，而非简单点估计 `p̂ ≥ 0.90`。原因：

- `p̂ = 成功次数/trials` 是点估计，受抽样噪声影响。trials=1000 时 `p̂` 的标准误差约 `√(p(1-p)/n) ≈ 0.9%`，单次抽样偏离真值 ±1% 属正常波动；
- 若用 `p̂≥0.90` 直接判定，真实 `P_conn` 略低于 0.90 时仍可能因抽样幸运而误判通过（约一半概率），结论不可靠；
- 单侧下界给出统计保证：**"真实概率以 95% 置信度不低于 `p_lower,95%`"**，要求 `p_lower,95%≥0.90` 意味着以 95% 把握该填充率确实满足指标，判定更保守、更稳健；
- 代价：通过判定需要 `p̂` 明显高于 0.90（约高 0.6~0.9%，与 trials 相关），φ_min 会略偏保守，这是为保证"达标"结论可信所必要的。

Wilson 单侧下界公式（`z=1.645`，单侧 95%）：

```
p_lower,95% = ( p̂ + z²/(2n) − z·√( p̂(1−p̂)/n + z²/(4n²) ) ) / ( 1 + z²/n )
```

### 2.3 最终确认策略

二分收敛后，对 `φ_min` 及其上、下邻点（`φ_min ± tol`）分别用 **`confirm_trials=4000`** 复核：

- `φ_min` 处应仍满足 `p_lower,95% ≥ 0.90`；
- `φ_min − tol` 处应不满足（或报告其实际 P̂/下界），从而确认 φ_min 是"刚好达标"的最低值；
- 4000 次复核下 `p̂` 标准误差降至 ≈0.5%，给最终结论更高置信度。

### 2.4 双边界模式对比

两种边界模式并行搜索并各自给出 φ_min：

- `PERIODIC_CONNECTED`（周期连续，跨边界片段合并）——物理解释；
- `WRAPPED_GEOMETRY_ONLY`（仅几何回绕，每片段独立）——敏感性对照。

问题 2 已表明两种模式结果差 <0.7%，预期 φ_min 差异很小；若出现明显差异需回溯解释。

## 3. 概率云理论对照

- **平均连接度**：`k̄ = ρ_A·V_AA`，其中 `ρ_A = N_A/V₀`，`V_AA = 2.5493×10⁹ nm³`（问题 2 已由 `4π∫r²q_AA(r)dr` 数值积分得到）。
- 代入 `N_A = round(φ·V₀/V_A)` 得：`k̄ = φ·V_AA/V_A`。
- **理论临界填充率**：令 `k̄=1`（渗流直觉上"节点平均连通数 ≥1 出现贯通倾向"），得

```
φ_theory = V_A / V_AA = 1.4137×10⁷ / 2.5493×10⁹ ≈ 0.005546 ≈ 0.5546%
```

- **与问题 2 实测互证**：φ=0.50% 时 `k̄=0.902<1`，实测 `P̂=0.915`、95% 单侧下界 ≈0.900（恰在阈值附近）；φ=0.60% 时 `k̄=1.081>1`、`P̂=0.9505`。可见 **P_conn 在 k̄≈1 附近快速穿越 0.90 阈值**，预期 φ_min 落在 0.45%~0.55% 区间，与理论临界 `φ_theory≈0.5546%` 同量级、互证。
- 偏差来源：介质 A 极细长（长径比 ≈83），单根可跨越大半个盒子、链式连接概率高，故 P_conn≥0.90 可在 `k̄<1`（φ 低于理论临界）时达到，φ_min 应略低于 φ_theory。
