# 问题 3 说明文档 — P_conn≥90% 的最低介质 A 体积分数

> 版本：2.0.0 ｜ 日期：2026-08-08 ｜ 说明文档（不构成论文）｜ 主流程 Monte Carlo 已完成

---

## 1. 问题重述

微构体为边长 10000nm 的立方体 `Ω=[-5000,5000]³`（体积 `V₀=10¹² nm³`）。介质 A 为直圆柱（长 `L_A=5000nm`、半径 `R_A=30nm`，单根体积 `V_A=π·30²·5000≈1.4137×10⁷ nm³`）。左右带电面为 `x=±5000`。导通判据：最短距离 `≤ δ=1.8nm`（A-A 轴距 ≤ 61.8nm，A-电极 ≤ 31.8nm）。

问题 3：**随机填充介质 A，求满足导通概率 `P_conn ≥ 0.90` 的最低体积分数 `φ_min`**。

优化问题形式：

```
min φ_A
s.t.  P_conn(φ_A) ≥ 0.90
```

## 2. 建模与方法

### 2.1 单调性与二分搜索

`P_conn` 随体积分数 `φ` **单调不减**（新增介质 A 只会增加连通边，不会删边），满足二分搜索前提。搜索区间取 `[φ_low, φ_high] = [0.20%, 0.70%]`：

- 下界 0.20%：处于渗流临界区以下（`k̄≈0.36` 远低于 1），预期不满足；
- 上界 0.70%：问题 2 实测满足（`P̂=0.975`，95% 单侧下界远高于 0.90）。

每轮取中点 `φ_mid` 跑 `trials=1000` 次 Monte Carlo：`p_lower(95%) ≥ 0.90` → 收缩上界，否则抬高下界。终止条件 `φ_high − φ_low ≤ tol=0.0001`（0.01%）或最大迭代 40 次（理论 `log₂(0.005/0.0001)≈5.6` 轮即收敛）。收敛后取保守上界 `φ_min = φ_high`。

### 2.2 判定标准：95% Wilson 单侧置信下界

判定采用 **95% Wilson 单侧置信下界 `p_lower,95% ≥ 0.90`** 而非简单点估计 `p̂ ≥ 0.90`。原因：trials=1000 时 `p̂` 标准误差约 0.9%，单次抽样偏离 ±1% 属正常波动；用点估计判定有一半概率把真实 `P_conn` 略低于 0.90 的填充率误判为通过。单侧下界给出统计保证——"真实概率以 95% 置信度不低于 `p_lower`"，判定更保守、更稳健（代价是 φ_min 略偏保守，为保证"达标"结论可信所必要）。

Wilson 单侧下界公式（`z=1.645`，单侧 95%）：

```
p_lower,95% = ( p̂ + z²/(2n) − z·√( p̂(1−p̂)/n + z²/(4n²) ) ) / ( 1 + z²/n )
```

### 2.3 最终确认策略

二分收敛后，对 `φ_low_end` 与 `φ_high_end`（=φ_min）分别用 `confirm_trials=4000` 复核，验证 φ_min 处是否仍满足 `p_lower ≥ 0.90`、φ_min−tol 处是否不满足（或报告其实际 P̂/下界），给最终结论更高置信度（4000 次下 `p̂` 标准误差降至 ≈0.5%）。

### 2.4 双边界模式对比

两种边界模式并行搜索各自给出 φ_min（延续 Q1/Q2 的敏感性对比）：

- `PERIODIC_CONNECTED`（周期连续，跨边界片段合并）——物理解释；
- `WRAPPED_GEOMETRY_ONLY`（仅几何回绕，每片段独立）——敏感性对照。

## 3. 概率云理论对照

- **等效连接体积**：`V_AA = 2.5493×10⁹ nm³`（问题 2 由 `4π∫r²q_AA(r)dr` 数值积分得到）。
- **平均连接度**：`k̄ = ρ_A·V_AA`，`ρ_A = N_A/V₀`，代入 `N_A = round(φ·V₀/V_A)` 得 `k̄ = φ·V_AA/V_A`。
- **理论临界填充率**（令 `k̄=1`）：

```
φ_theory = V_A / V_AA = 1.4137×10⁷ / 2.5493×10⁹ ≈ 0.5546%
```

- **与问题 2 实测互证**：φ=0.50% 时 `k̄=0.902<1`，实测 `P̂=0.915`、95% 单侧下界 ≈0.900（恰在阈值附近）；φ=0.60% 时 `k̄=1.081>1`、`P̂=0.9505`。预期 φ_min 落在 0.45%~0.55%，与理论临界同量级。
- **偏差来源**：介质 A 极细长（长径比 ≈83），单根可跨越大半个盒子、链式连接概率高，故 `P_conn≥0.90` 可在 `k̄<1`（φ 低于理论临界）时达到，φ_min 应略低于 φ_theory。

## 4. Monte Carlo 二分搜索（验算层）

单次仿真沿用 Q2 流程：随机生成 N_A 根圆柱 → 解析切段回绕 → AABB 宽相位筛候选 → 精确线段-线段距离 ≤61.8nm 连边 → 电极判据 → DSU 判定 L/R 贯通。每个评估点由主 rng 一次性派生 `max(trials, confirm_trials)` 个子种子，**任意评估顺序、串行/并行/重复运行结果完全一致**（seed=42 可复现）。`--workers 8` 按 trial 批次多进程并行。

## 5. 参数表

| 参数 | 值 | 说明 |
|---|---|---|
| φ 搜索区间 | [0.20%, 0.70%] | 下界低于临界区、上界 Q2 实测已满足 |
| trials | 1000 | 二分中点判定的 MC 次数 |
| confirm_trials | 4000 | 收敛后 φ_min 上下邻点复核次数 |
| tol | 0.0001（0.01%） | φ 绝对精度 |
| 最大迭代 | 40 | 二分安全上限（实际 6 轮收敛） |
| 判定标准 | `p_lower,95% ≥ 0.90` | 95% Wilson 单侧置信下界 |
| seed | 42 | 全流程可复现（子种子机制） |
| workers | 8 | 多进程并行核数 |
| 边界模式 | periodic_connected / wrapped_geometry_only | 双模式对比 |

关键常量：`V₀=10¹² nm³`、`V_A≈1.4137×10⁷ nm³`、`V_AA=2.5493×10⁹ nm³`、`N_A=round(φ·V₀/V_A)`。

## 6. 结果

### 6.1 主结果（trials=1000, seed=42, 双模式并行二分）

| boundary_mode | φ_min | N_A | p̂(φ_min) | p_lower,95%(φ_min) | k̄(φ_min) | φ_theory | 迭代 |
|---|---|---|---|---|---|---|---|
| periodic_connected | **0.5125%** | 363 | 0.9280 | 0.9134 | 0.9254 | 0.5546% | 6 |
| wrapped_geometry_only | **0.4969%** | 351 | 0.9210 | 0.9058 | 0.8948 | 0.5546% | 6 |

- 双模式在 `trials=1000` 判定下均满足 `p_lower ≥ 0.90`；
- 两种边界模式 φ_min 相差仅 ~0.016 pp（0.5125% vs 0.4969%），**结论对边界解释稳健**；
- 图：`conductive_microstructure/results/problem3/problem3_bisection.png`（二分搜索过程：p̂ 与 p_lower 迭代轨迹、φ_min 竖线、k̄=1 理论临界线）。

### 6.2 确认点（confirm_trials=4000）

| φ | boundary_mode | connected_count | p̂ | p_lower,95% |
|---|---|---|---|---|
| 0.5047%（φ_min−tol） | periodic_connected | 3671/4000 | 0.9178 | **0.9103** |
| 0.5125%（φ_min） | periodic_connected | 3662/4000 | 0.9155 | **0.9080** |
| 0.4891%（φ_min−tol） | wrapped_geometry_only | 3623/4000 | 0.9058 | 0.8979 |
| 0.4969%（φ_min） | wrapped_geometry_only | 3630/4000 | 0.9075 | 0.8997 |

- **periodic**：φ_min 及 φ_min−tol 在 4000 次复核下均满足 `p_lower ≥ 0.90`（0.9080 / 0.9103），说明 1000 次的二分判定偏保守，真实 90% 阈值略低于 0.5125%；
- **wrapped**：φ_min 处 4000 次复核 `p_lower=0.8997`，仅以 ~0.0003 微弱低于 0.90（`p̂=0.9075` 仍高于 0.90），处于统计噪声边界；φ_min−tol 处 `p_lower=0.8979`。整体确认 90% 阈值落在 **≈0.49%~0.51%** 区间。

## 7. 结果解读

1. **最终结论：`P_conn≥90%` 的最低介质 A 体积分数为 `φ_min ≈ 0.50%`（双模式给出 0.5125% / 0.4969%）**，对应 `N_A ≈ 351~363` 根。
2. **与理论互证**：实测 φ_min（0.50%）略低于 `φ_theory = 0.5546%`（k̄=1 临界），符合"极细长介质 A 链式连接使 `P_conn≥0.90` 可在 `k̄<1` 时达到"的预期——φ_min 处 `k̄=0.925`（periodic）/ `0.895`（wrapped），均 <1。概率云理论的 k̄ 指标对 90% 导通边界的预测（~0.55%）与实测（~0.50%）同量级、偏差仅 ~0.05pp，验证成立。
3. **与问题 2 互证**：Q2 实测 φ=0.50% 时 `P̂=0.915`、单侧下界 ≈0.900 恰在阈值附近，与 Q3 求得的 φ_min≈0.50% 自洽（最低可行 φ 略低于 0.50% 与 wrapped 结果 0.4969% 吻合）。
4. **双模式稳健性**：periodic 与 wrapped 的 φ_min 仅差 ~0.016pp，延续 Q2"双模式结果差 <0.7%"的结论——**90% 导通最低填充率对边界解释不敏感**。
5. **判定置信度**：全部判定基于 95% 单侧置信下界而非点估计；4000 次复核显示 periodic 的 φ_min 甚至偏保守（下界 0.9080 仍达标），wrapped 的 φ_min 恰在统计边界（下界 0.8997），真实阈值 ≈0.49%~0.51%。论文建议表述：**φ_min ≈ 0.50%（保守上界 0.5125%）**。

## 9. 局限与说明

- 判定采用 `p_lower(95%) ≥ 0.90`，φ_min 为**保守上界**；4000 次确认显示 periodic 的真实阈值略低于 0.5125%，wrapped 的 0.4969% 恰在统计边界（4000 次下 p_lower=0.8997，微弱低于 0.90）。
- 二分中点 trials=1000 的单点抽样误差约 ±0.9%，φ_min 的绝对精度（0.01%）受 MC 噪声限制；如需更高精度可增大 trials 或对 φ_min 邻域做精细扫描。
- 圆柱-圆柱导通采用 capsule 近似（端面误差 ≪ δ，可忽略）；有限盒子未做尺寸外推。
- `V_AA` 在 r 步长 25nm 网格上数值积分，长尾贡献小、误差可忽略。
- 本问结论将作为问题 4（A/B 混合体系最低成本）的 A 介质基准：`φ_min≈0.50%` 对应纯 A 体系成本约 `0.50%×10¹² nm³ × 1.05 元/μm³`（单位换算 1μm³=10⁹nm³），可作为 Q4 可行域上界参照。
